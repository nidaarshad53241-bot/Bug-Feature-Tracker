# Bug & Feature Tracker

A simple Python console application to track bugs and feature requests.

## Features
1. Add Entry - Add new bug or feature with title and description
2. View Entries - View all tracked entries
3. Show Statistics - Display total bugs and features count
4. Input Validation - Handles empty titles and invalid menu choices

## How to Run

## Validation
- Empty title is not allowed
- Invalid menu choice (e.g., 9) shows error message instead of crashing
